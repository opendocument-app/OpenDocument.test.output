A document reader sees everything you open with it — contracts, notes, payslips.
This one has nowhere to send any of it: there is no server behind the app, and the
code that opens your files is public.
Documents are decoded on your device. There is no server to send them to, no account to make,
and nothing to delete afterwards.
The apps, the rendering engine and its bindings are public. Read the code that opens your files, or
build it yourself.
